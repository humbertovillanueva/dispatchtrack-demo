# DispatchTrack Lite demonstration

Public compiled assets for a portfolio demonstration.

Create deliveries, assign drivers, record outcomes, and review history. Records are stored only in each browser; nothing is shared between devices. Use fictional data only. This is not a hosted Java API or a commercial delivery service.

This repository contains build output, not the private application repository history.

## Try the delivery workflow

Open the [live demo](https://humbertovillanueva.github.io/dispatchtrack-demo/) and use fictional details:

1. Create a delivery with **New delivery**.
2. Open the delivery and assign a driver before dispatching it.
3. Move it to **In Transit**, then record a completion note and mark it **Delivered**.
4. Review its history, then reload the page to check that the record is still saved in this browser.

Clearing browser storage removes your demo records. Another browser or device starts with its own sample data.
